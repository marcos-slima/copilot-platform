# Copilot Platform documentation

This repository owns shared Python core, core-ui and operational artifacts,
with independent releases. [Current documentation](../README.md) is maintained
in Portuguese. [Development](../DEVELOPMENT.md), [contracts](../../packages/core/docs/CONTRACTS.md)
and [release policy](../RELEASES.md) describe the split architecture.

Legacy English guides describe the former IIC monorepo. Their snapshots are
[historical](../history/README.md), not current product setup instructions.
[IIC](https://github.com/marcos-slima/integration-incident-copilot) and
[FISC](https://github.com/marcos-slima/fiscal-incident-support-copilot) maintain product guides.
