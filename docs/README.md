Instruções de instalação e deployment dos produtos pertencem a
[IIC](https://github.com/marcos-slima/integration-incident-copilot/blob/master/docs/README.md)
e [FISC](https://github.com/marcos-slima/fiscal-incident-support-copilot/blob/main/docs/README.md).
As referências arquiteturais/GRM preservam decisões e contexto anteriores;
seções herdadas de implantação não substituem os guias atuais dos produtos.
Português é a fonte atual; [o índice inglês](en/README.md) indica os limites das traduções.
