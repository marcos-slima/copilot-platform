# Contribuição

Bugs comuns e mudanças de SDK, core-ui ou operação pertencem aqui.
Comportamento específico de IIC/FISC pertence ao produto e referencia o PR comum.
Mudanças devem preservar contratos ou declarar migração e incremento major.
Core, UI e operações não precisam de release conjunta.
Rodar quality gate, suíte com cobertura e testes UI antes de commit.
Registrar decisões formais conforme CLAUDE.md. Dados de teste são sintéticos.
